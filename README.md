## About the Course

This course introduces the fundamental skills required to integrate Generative AI into .NET applications.

It covers configuring OpenAI and Azure OpenAI accounts, building a basic chatbot using .NET Core, and applying best practices for error handling, security, and responsible AI development.

A dedicated section focuses on content filtering and AI safety to help developers prevent inappropriate or harmful AI-generated responses.

## Learning Objectives

- Understand the fundamentals of Generative AI integration in .NET.
- Configure and connect OpenAI and Azure OpenAI services.
- Build a basic AI-powered chatbot using .NET Core.
- Integrate Large Language Models (LLMs) into .NET applications.
- Handle API errors and exceptions effectively.
- Apply security best practices when working with AI APIs.
- Implement content filtering and moderation.
- Understand AI safety considerations in real-world applications.

## Technologies & Concepts

- **Programming Language:** C#
- **Framework:** .NET Core

- **AI Concepts:** Generative AI, Large Language Models (LLMs)
- **Application Development:** AI-powered Chatbots
- **Security:** API Security, Content Filtering
- **Best Practices:** Error Handling, AI Safety

## Practical Outcomes

By completing this course, developers gain foundational knowledge to:

1. Integrate OpenAI capabilities into existing .NET applications.
2. Develop conversational AI features.
3. Configure and use cloud-based AI services.
4. Build safer and more reliable AI-powered backend systems.
